## What landed since v1.0.0

- **v1.0.1** — Explorer arrow regression. Six bindings that removed
  built-in `list.collapse`/`list.expand` and mapped Left-on-a-file to
  `list.focusUp` (previous *row*, not parent) replaced by one binding.
  Also caught a 161 KB `global-bundle.pem` being packaged into the VSIX.
- **v1.1.0** — Editing category 17 → 49 entries. Folding, word
  navigation, line ops, selection, font size, quick docs. New
  `useCamelHumpsWords` setting.
- **Icon** — `media/icon.png`, generated by `media/build-icon.js`
  (pure Node, no deps). macOS has no SVG rasterizer on PATH and
  `qlmanage -t` bakes in a Quick Look drop shadow, so the script
  rasterizes signed-distance fields directly. `media/icon.svg` is the
  design source of truth; re-run the script after editing it.

## The measurement discipline is the important part

`.claude/roadmap.md` §2 said to read the VS Code source before writing
any binding. Doing that on v1.1.0 found:

- 11 of 27 planned keys were **already macOS defaults**
- 2 of those were planned with the **wrong command** (`⌥→` → the plan
  said `cursorWordRight`, the default and IntelliJ both want
  `cursorWordEndRight`). Shipping the plan verbatim would have regressed.
- 5 keys collided with VS Code defaults nobody had checked (window zoom
  on `⌘-`/`⌘=`/`⌘⇧-`/`⌘⇧=`, Quick Fix on `⌘.`)

Results are recorded in `.claude/conventions.md` under "Measured macOS
defaults" with source line numbers. **Do not re-derive them.** Apply the
same procedure to v1.2.0 — the queue of keys to measure is at the end of
roadmap §2.

## Next: Marketplace publish

Everything is prepared. The remaining steps need the account owner:

1. Create the publisher if it does not exist yet:
   <https://marketplace.visualstudio.com/manage> → Create publisher →
   ID must be exactly `jungsehui` (it is hardcoded in `package.json`).
2. Create an Azure DevOps PAT:
   <https://dev.azure.com> → User settings → Personal Access Tokens →
   New Token. **Organization: All accessible organizations.**
   **Scopes: Custom defined → Marketplace → Manage.** Anything narrower
   fails at publish time.
3. Publish:
   ```bash
   export PATH="$HOME/.nvm/versions/node/v22.22.1/bin:$PATH"
   npx vsce login jungsehui     # paste the PAT
   npx vsce publish             # or: npx vsce publish --packagePath custom-intellij-nav-1.1.0.vsix
   ```
4. Verify from a clean profile:
   ```bash
   code --install-extension jungsehui.custom-intellij-nav
   ```
5. Add the Marketplace badge to `README.md` once the listing is live.

PATs expire (max 1 year). If CI auto-publish is wanted later, fill in the
`publish` job stub in `.github/workflows/release.yml` with
`vsce publish -p ${{ secrets.VSCE_PAT }}` and add the secret.
